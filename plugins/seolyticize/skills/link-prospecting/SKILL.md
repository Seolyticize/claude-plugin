# Link prospecting

1. Competitors from the brief, plus `find_serp_competitors` if the brief has none.
2. `get_link_intersect` — sites linking to several competitors but not the client. Rank by how many competitors they link to and their authority.
3. `get_ai_visibility` (sources) and `get_ai_visibility_results` — the publications assistants read when answering the client's questions are prospects twice over.
4. For each prospect, say why it would link (what it covers, what the client could offer), and flag anything that looks like a link scheme — never recommend buying links.
5. Deliver a short, ranked list with a one-line pitch angle each; save it as a `research` entry and, if asked, as a written report.
